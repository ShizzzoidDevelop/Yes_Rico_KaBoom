# Yes Rico KaBoom - Neon Minesweeper

Классический Minesweeper в стиле Katana ZERO с неоновыми эффектами, 32-bit пиксель-артом и пост-обработкой.

## 🎮 Особенности

- **Классические правила** Minesweeper без изменений
- **Неоновый визуал** в стиле Katana ZERO с bloom, scanlines, chromatic aberration
- **32-bit пиксель-арт** с динамическим освещением
- **Модульная архитектура** для легкого расширения
- **macOS нативный** .app bundle с Retina поддержкой
- **Шейдерный pipeline** для VFX эффектов

## 🚀 Быстрый старт

### Требования
- Java 17+
- macOS 10.15+ (Intel/Apple Silicon)

### Запуск разработки
```bash
./gradlew desktop:run
```

### Сборка для macOS
```bash
./build-macos.sh
open "dist/Yes Rico KaBoom.app"
```

## 🎯 Управление

- **ЛКМ** — открыть клетку
- **ПКМ** — поставить/снять флаг  
- **Средний клик** — поставить/снять вопрос
- **Двойной клик** — chording (быстрое открытие соседей)
- **N/R** — новая игра
- **P** — пауза
- **ESC** — возврат в меню
- **F** — режим флагов
- **Space** — быстрая подсказка

## 🏗️ Архитектура

```
core/
├── core/           # Игровая логика (Minefield, GameManager)
├── input/          # Обработка ввода (InputManager)
├── render/         # Рендеринг и шейдеры (ShaderManager)
├── ui/             # Экраны (MenuScreen, GameScreen)
└── assets/         # Ресурсы (шейдеры, звуки, спрайты)
```

## 🎨 Визуальные эффекты

- **Bloom** — неоновое свечение ярких объектов
- **Scanlines** — CRT эффект для ретро-стиля
- **Chromatic Aberration** — VHS искажения
- **VHS Noise** — аналоговые помехи
- **Dynamic Lighting** — подсветка при наведении

## 🔧 Разработка

### Добавление новых эффектов
1. Создайте шейдер в `core/src/main/resources/shaders/`
2. Добавьте в `ShaderManager`
3. Настройте параметры в `GameScreen`

### Добавление анимаций
1. Создайте спрайтшит в Aseprite/PyxelEdit
2. Добавьте в `assets/sprites/`
3. Реализуйте в `AnimationManager`
